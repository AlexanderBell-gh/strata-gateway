# Documentation

This directory contains the documentation for Strata. The structure is:

- `compliance/` — regulatory and standards alignment (NIST AI RMF, ISO/IEC 42001, UK GDPR/ICO, DUAA). See [`compliance/NIST-AI-RMF.md`](./compliance/NIST-AI-RMF.md) and [`compliance/ISO-42001-CLAUSES.md`](./compliance/ISO-42001-CLAUSES.md) for detailed mappings.
- `usage/` — integration guides, SDK examples, and API reference (to be added).
- `architecture/` — high-level design notes and decision logs.
